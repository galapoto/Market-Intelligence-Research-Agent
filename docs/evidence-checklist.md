# QuickSuite evidence checklist

This public repository contains textual summaries sourced from the author's earlier coursework and tests added after completion. It does **not** currently include native QuickSuite Space exports.

- [x] Research question and country/market constraints documented
- [x] Five executive-level insights and conditional recommendation
- [x] Five-insight reliability assessment, source hierarchy and limitations
- [x] Selected historical data transcription with executable arithmetic tests
- [ ] Original Quick Research PDF (check redistribution rights and source attributions first)
- [ ] Approved/cropped QuickSuite screenshots showing Space, agent configuration and research prompts
- [ ] Original analyzed Kaggle/IEA dataset version, URL/hash and transformation record
- [ ] Re-verify time-sensitive 2025–2026 sources before any decision use

**Do not upload:** account credentials, private workspace URLs, student IDs, access tokens, unlicensed reports or unrelated personal files.
